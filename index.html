O systemie

To jest oficjalna strona monitorująca działanie usług portalu Mapa Beskidu. Monitorujemy dostępność głównej aplikacji webowej (Frontend), serwerów API (PHP Backend) odpowiedzialnych za punkty POI i logowanie, a także integracji zewnętrznych (IMGW), które dostarczają ostrzeżenia meteorologiczne dla Beskidów.

System automatycznie diagnozuje błędy i powiadamia redakcję o usterkach w czasie rzeczywistym. Hosted on GitHub Pages.
